# Changelog

All notable changes to Python Viewer are documented here.

## 0.1.0 - 2026-06-07

- Initial local release.
- Add read-only `.py` source view with line numbers and lightweight syntax highlighting.
- Add structure view for imports, decorators, classes, functions, methods, and top-level constants.
- Add symbol and source filtering, jump-to-line behavior, refresh, parse diagnostics, and render caps.
